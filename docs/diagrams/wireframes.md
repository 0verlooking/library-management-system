## 5. Кольорова схема

### Основні кольори:
- **Основний:** #2c3e50 (темно-синій) - header, footer
- **Акцент:** #3498db (яскраво-синій) - кнопки, посилання
- **Успіх:** #27ae60 (зелений) - доступні книги, успішні дії
- **Попередження:** #f39c12 (помаранчевий) - попередження
- **Помилка:** #e74c3c (червоний) - прострочення, помилки
- **Фон:** #f5f5f5 (світло-сірий) - основний фон
- **Білий:** #ffffff - картки, форми

### Статуси:
- **Активна позика:** 🟢 Зелений бордер
- **Прострочена позика:** 🔴 Червоний бордер
- **Повернена книга:** 🔵 Синій бордер
- **Доступна книга:** ✅ Зелений індикатор
- **Недоступна книга:** ⚠️ Помаранчевий індикатор

## 6. Адаптивний дизайн

### Desktop (>1024px)
- Сітка з 3-4 колонками для книг
- Горизонтальна навігація
- Розширена панель пошуку

### Tablet (768px - 1024px)
- Сітка з 2 колонками для книг
- Горизонтальна навігація
- Компактна панель пошуку

### Mobile (<768px)
- Список у 1 колонку
- Hamburger menu для навігації
- Спрощена панель пошуку
- Touch-friendly кнопки

---

## 7. Інтерактивні елементи

### Hover ефекти:
- Картки книг: підняття + тінь
- Кнопки: зміна кольору
- Посилання: підкреслення

### Анімації:
- Плавна поява елементів
- Анімація завантаження
- Transition для всіх інтерактивних елементів

### Feedback:
- Toast повідомлення для дій
- Індикатори завантаження
- Підтвердження для критичних дій
